Windows can already share files. It just makes you earn it.

Getting one Word document onto the PC across the room means network profiles, discovery settings, firewall rules, two different kinds of permissions, a password that isn’t your PIN, and error messages that read like riddles. So people give up and email the file to themselves, upload it to a cloud drive, or go looking for a USB stick.

Things you never need to look up again:

  • Network discovery
  • Private or Public network?
  • Firewall port 445
  • SMB guest access
  • Share permissions vs NTFS permissions
  • \\192.168.1.23\Users
  • PIN or password?
  • Microsoft account or local account?
  • System error 1219

Set up the other PC once. Then forget about it.

  1. Choose “Receive files on this PC”

    Open FuckingShareIT on the PC that should receive files and pick the one button that says so.

  2. It looks before it touches anything

    First a read-only check of how this PC’s network and sharing are set up. Then a short, exact list of what it will change — before Windows asks for administrator approval.

  3. Approve once

    It creates a dedicated inbox in Public Documents and shares only that folder, only with your private local network. The folder you send from is never shared.

  4. Close the app

    Receiving keeps working with FuckingShareIT closed. Windows’ own file sharing does the carrying — there’s no extra background service of ours running.

Plain answers.

Do both PCs need FuckingShareIT?

The PC you send from uses it to send. The receiving PC needs it once, to set up receiving. After that, the receiving PC doesn’t need the app open — Windows receives the files by itself.

Does my file go through the internet?

No. It goes straight from one PC to the other over your own network, using the file sharing built into Windows. Nothing is uploaded anywhere and there’s no account to make.

Does it work between two houses, or over mobile data?

No. Both PCs need to be on the same private local network — behind the same home router, wired or Wi‑Fi. It isn’t a cloud service or a remote-access tool, and it doesn’t pretend to be.

Is it safe?

Here’s the honest version. By default the receiving inbox doesn’t ask for a password — that’s what makes it effortless at home. It also means any device on that same private network can open, add or change files in that one folder. Nothing else on the PC is shared.

The default is about convenience on a network you trust, not encryption. Don’t use it on hotel or café Wi‑Fi. If you’d rather require a sign-in, Advanced has account-based access with signed SMB.

What exactly changes on the receiving PC?

It creates one folder, FuckingShareIT Received in Public Documents, shares only that folder, and scopes its firewall rule to private networks and the local subnet. Passwordless setup also adjusts Windows guest access and SMB signing requirements. The app shows the full changes before administrator approval and records them for Undo. Account-based access keeps SMB signing enabled.

What happens to my original file?

Nothing. It’s copied, never moved, and the folder it sits in is never shared.

What if a file with the same name is already there?

Both are kept. The new copy gets a number, like Letter (2).docx. Nothing gets overwritten.

What if I cancel halfway, or the copy fails?

Cancelling tries to remove only its own unfinished copy. If Windows prevents cleanup, the app identifies the remaining partial file and explains what to do. It only says Done when the saved copy matches the original in size and SHA-256 fingerprint. If something goes wrong, it says so and tells you what to try.

The other PC doesn’t show up.

Make sure it has been set up to receive and is on the same network. Then choose Look again, or Find by name and type its PC name. Advanced → Diagnostics shows what’s in the way, in words.

Do I need to be an administrator?

Receiving setup needs administrator approval. Ordinary sending doesn’t, but a Windows connection repair can need a separate reviewed approval on the sending PC.

Portable or installer?

Portable is one EXE: download it and run it. The installer is the same app, installed like a regular Windows program. Pick whichever you like; they work the same.

Mac, Linux, phone?

No. It’s a native Windows 10/11 x64 app for getting files from one Windows PC to another on a local network, and it’s very good at exactly that.
