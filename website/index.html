Why I made this

I was sick and tired of Windows' shitty file sharing. I use local accounts. Every time I reinstall a PC, it's the same job: network profiles, discovery settings, permissions and a password prompt that won't accept my PIN. All this to move a file between two PCs I own.

So I built FuckingShareIT. Open it on each PC, choose Set up this PC and approve the Windows changes. It handles the sharing settings, firewall and receiving folder. After that, I right-click a file, choose the other PC and save it.

Local accounts work, including ones without a password. You don't need a Microsoft account or a cloud service. Your files go directly between your PCs.

You can also share folders and whole drives, with read-only or read/write access. Windows keeps them available with the app closed.

Who can access my files?

Passwordless mode lets devices on your private network open, add or change files in the receiving folder. It relaxes Windows guest and signing protections. Use a network you trust, or choose a sharing account and password in the app. You review the Windows changes before approving them and can undo them under Advanced.
