Setup & other options

On the receiving PC, choose Receive files on this PC once. Review the Windows changes before you approve. Receiving works with the app closed.

Passwordless mode lets devices on your private network read or change files in the shared inbox. It changes Windows guest access and SMB signing settings. Use a network you trust, or choose a dedicated sign-in under Advanced.

Advanced also has folder and drive sharing, read-only access, saved PCs and mapped drives.
